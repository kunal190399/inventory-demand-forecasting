# Predictive Analytics for Inventory & Resource Planning

Which raw materials should a planner order to meet projected finished-goods demand?

This independent portfolio project is at the planning stage. The proposed study uses synthetic technical-textiles manufacturing data. Implementation and evaluation are scheduled for a later build.

**Planned tools** — Python, scikit-learn, SQL, Streamlit and Power BI.

## First milestone

Work through one SKU, two raw materials and an open purchase order before fitting a model.
